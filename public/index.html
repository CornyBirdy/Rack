Set up Cloudflare

      

        Publish a process on a permanent hostname of your own domain. Needs a Cloudflare account
        and a domain on Cloudflare. Run these once, by hand, in a terminal — the login opens a
        browser and writes credentials to ~/.cloudflared, so Rack doesn't do it for
        you. Click a command to copy it.
      

      
    
        
  1. 
          Install cloudflared
    
          winget install --id Cloudflare.cloudflared
          
        
    2. 
        
  2. 
          Log in and pick your domain in the browser
    
          cloudflared tunnel login

Claude connector

      

        An MCP server so Claude can see your apps, read their logs, and start, stop, restart and
        update them — "why is Shelf down?", "update everything". It runs on a port of its own that
        answers nothing else, so you can publish it without publishing this dashboard.
